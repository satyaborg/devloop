a single bash executable for the agentic dev loop

$ curl -fsSL https://devloop.sh/install | bash

macOS. Requires the codex and claude CLIs.

## WHY

Intent is clearest when you spec the work and judged best when you review the result. The messy middle is where agents drift, so devloop makes it a spec-driven, verifiable loop instead of an open-ended chat.

The coder and reviewer are different model families: LLM judges favor their own output, a blind spot humans don't share (Panickssery et al., 2024). So humans stay in the loop only where judgment pays off, at the spec and the final sign-off, while automated cross-family review handles the rest.

# SPEC-DRIVEN CODE AND REVIEW LOOP

devloop runs a local implement-and-review loop for agent-written code. You write a short, verifiable spec. By default Codex makes the change, Claude Code reviews it, and Codex retries until the work is accepted, stalled, unclear, or out of passes.

No orchestration service, no dashboard, no telemetry. Just one auditable Bash script that drives the agent CLIs you already have, in isolated git worktrees, and writes every track, review, and report to disk.

Built for developers who want a tight, auditable loop around the coding agents they already run, without giving up control of their checkout.

## HOW IT WORKS

Every run is the same loop, repeated until a verdict settles it:

  • * spec -- you write a short markdown spec with acceptance criteria.
  • * code -- Codex implements the change in an isolated worktree.
  • * review -- Claude Code reviews against the spec and quality gates.
  • * loop -- retry on REJECT, stop on ACCEPT, stall, or max passes.

Up to 5 passes by default (clamped 1-10), a 30-minute timeout, and a .devloop/verify hook that blocks acceptance when it fails.

## QUICK START 

# generate a spec from a one-liner
$ devloop spec "add retry behavior to the chat sender"

# run the loop from the repo you want changed
$ devloop .specs/change.md

# open a PR after an accepted run
$ devloop --create-pr .specs/change.md

## WHAT DEVLOOP DOES

  • * Runs in isolated sibling git worktrees by default.
  • * Runs a preflight: git identity, agent CLIs, installed skills, and gh for PRs.
  • * Lints specs for a title, valid frontmatter, and strict acceptance criteria.
  • * Commits eligible changes after each coder pass.
  • * Writes tracks, reviews, reports, logs, and spec snapshots under .codex/.
  • * Never pushes or opens a PR unless you pass --create-pr.

## SWAPPABLE AGENTS

Codex and Claude Code are interchangeable on either side of the loop:

flag meaning
--codercodex | claude -- who implements
--reviewercodex | claude -- who reviews
--in-placerun in the current worktree
--no-strictweaken strict review gates
